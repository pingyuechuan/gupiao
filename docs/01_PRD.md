## 1. 产品定位

| 项 | 内容 |
|---|---|
| 名称 | Project Phoenix |
| 定位 | **AI Investment Coach（AI 投资教练）** |
| **不是** | 股票软件 / 行情软件 / 看盘软件 |
| 一句话 | 帮助普通投资者，每天知道：**今天应该怎么操作** |
| 使命 | 做**最值得信任**的 AI 投资教练，而不是功能最多的股票软件 |

### 1.1 我们不做什么（明确边界）

- ❌ 不做 Level-2 行情、逐笔委托、龙虎榜等**看盘工具**
- ❌ 不做社区、晒单、跟单、大 V 荐股
- ❌ 不做实盘交易、下单通道、资金托管
- ❌ 不做"功能越多越好"的堆叠

### 1.2 我们只做三件事

1. **建立用户信任** — 每个建议都能展开"为什么"，且历史准确率公开可查
2. **帮助用户成长** — 记住用户的错误，纠正行为，量化成长
3. **长期陪伴投资** — 每天一条明确指令，形成日常习惯

## 2. 目标用户

| 维度 | 描述 |
|---|---|
| 核心人群 | A 股个人投资者，**尤其是小白 / 1–3 年经验者** |
| 典型痛点 | 看得懂 K 线但不知道该怎么操作；追涨杀跌；不设止损；反复亏在同一个错误上 |
| 使用场景 | 早盘前 5 分钟看今天怎么办；盘中查一只票能不能买；收盘后复盘 |
| 明确排除 | 职业交易员、量化团队、机构用户（他们不需要教练） |

### 2.1 用户画像（Onboarding 采集，7 题 / 约 30 秒）

| 字段 | 取值 |
|---|---|
| `principal` | 本金（元） |
| `riskTolerance` | 低 / 中 / 高 |
| `period` | 短线 / 中线 / 长线 |
| `targetReturn` | 跑赢通胀 / 年化8% / 年化15%+ / 财务自由 |
| `age` | <30 / 30-45 / 45-60 / >60 |
| `experience` | 小白 / 1-3年 / 3年以上 |
| `style` | 稳健 / 价值 / 成长 / 激进 |
| `profileType` | 由 `style` 推导：保守型 / 价值型 / 成长型 / 激进型 |

画像是 **AIMS 用户匹配度（占最终评分 30%）** 的唯一输入来源。

## 4. 核心功能清单（0.7 现状）

### 4.1 AIMS — AI 投资决策引擎 🔒 护城河

全产品唯一 AI 来源。五维等权评分，输出统一结论。详见 [07_AIMS](./07_AIMS.md)。

| 维度 | 权重 |
|---|---|
| 市场 | 20% |
| 行业 | 20% |
| 资金 | 20% |
| 趋势 | 20% |
| 风险 | 20% |

最终输出：**可以买指数 / 上涨概率 / 建议仓位 / 风险指数 / 一句话建议**

### 4.2 AI 记忆系统 🔒 护城河

记录用户长期行为：画像、风险偏好、持仓、历史操作、常犯错误、投资目标。

- 已实现：操作记录（买入/加仓/持有/减仓/卖出）、**追高识别**（买入且当日涨幅 >5%）
- 已实现：连续追高 ≥2 次 → AIMS **强制降仓至 40% 并转为「观望」**，附带行为提示
- 错误类型：`chase_high`（追高）/ `no_stop`（不设止损）/ `overtrade`（过度交易）

### 4.3 AI 成长系统

- 等级 Lv1–Lv100，经验值 `xp`，`level = floor(xp/120)+1`
- 连续行为统计：学习 / 正确操作 / 止损 / 复盘 / 不追高 / 交易
- 勋章体系（10 枚），例：连续 7 天没有追高 → **冷静投资者**

### 4.4 AI 历史准确率 🔒 护城河（信任基石）

- 每条 AI 推荐落库（含推荐时价格），后续回补现价判定胜负
- 展示近 30 天：推荐数 / 上涨数 / 成功率
- 可点击查看历史推荐明细

> **这是建立信任的最关键功能**：敢公开准确率的 AI 投顾极少。

### 4.5 AI 投资日记

每日自动生成：今日市场 / 今日操作 / 今日收益 / 今日总结，累积为成长记录。

### 4.6 AI 解释（可解释性）

任何建议均可展开"为什么"，显示：五维评分 + 用户匹配度 + 最终评分 + 行为提示。

### 4.7 Beta 反馈系统

右下角 🐞 常驻入口，支持 Bug / 建议 / 评分（星级）/ 截图 / 联系方式，统一管理。

### 4.8 Beta 版本标识

首页与「我的」页展示：`Project Phoenix · Beta · Version 0.7`

## 5. 页面需求（3 秒法则）

每个页面必须在 **3 秒内**回答"现在该怎么办"。

| 页面 | 首屏必须回答 | 数据来源 |
|---|---|---|
| 首页 Today | 今天大盘能不能做？今天该关注什么？ | AIMS + 大盘上下文 |
| AI 发现 | 今天有哪几只值得看？各自该怎么操作？ | AIMS（`getRecommendations`） |
| 持仓 | 我手里的票该持有还是减仓？ | AIMS（`getBatchAdvice`） |
| AI 教练 | 我今天的行动计划是什么？ | AIMS |
| 我的 | 我成长到哪一步了？AI 准不准？ | 本地 Store |
| 个股详情 | 这只票现在能不能买？买多少？止损在哪？ | AIMS（`getStockAdvice`） |

**禁止**：任何页面把「一堆数据」当成交付物。数据必须转化为**指令**。
