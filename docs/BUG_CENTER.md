## 分级标准

| 等级 | 定义 | 处理时限 |
|---|---|---|
| **P0** | 无法使用（白屏 / 崩溃 / 核心数据全空 / 数据错误误导用户） | **立即修复**，可热修 |
| **P1** | 影响体验（关键路径卡顿、结论不一致、降级失效） | 本 Sprint 内修复 |
| **P2** | 普通 Bug（文案、边界、非关键样式） | 下一版本 |
| **P3** | 优化建议 | 进 [FEATURE_BACKLOG](./FEATURE_BACKLOG.md) |

> **P0 未清零，禁止发布。**

## 提交规范

新 Bug 必须包含：

```
ID：BUG-XXX
等级：P0 / P1 / P2 / P3
标题：一句话
复现步骤：1. 2. 3.
预期 / 实际：
环境：浏览器 + 版本号
证据：截图 / 控制台错误
```

来源为用户反馈的，需标注 `来源：Feedback #ID`。
同一问题被反馈 **≥3 次**，自动升级为 **P1**。
