## v0.7 — Beta 首发：AIMS 护城河

**发布日期**：2026-08-04　｜　**版本目标**：建立 AIMS（AI 能力成型）　｜　**Sprint**：S1

### 新增

**AIMS — AI 投资决策引擎（全产品唯一 AI 来源）**
- 五维等权评分：市场 / 行业 / 资金 / 趋势 / 风险，各 20%
- 最终评分 = 五维分 × 70% + 用户匹配度 × 30%
- 统一输出：可以买指数 / 上涨概率 / 建议仓位 / 风险指数 / 一句话建议
- 新增模块：`src/aims/{types,context,scoring,engine}.ts`

**AI 记忆系统**
- 记录用户历史操作，自动识别追高 / 不止损 / 过度交易
- **行为矫正**：连续追高 ≥2 次时，AI 主动降仓至 40% 并转为「观望」，并说明原因
- 个股详情页新增操作记录入口（买入/加仓/持有/减仓/卖出）

**AI 成长系统**
- Lv1–Lv100 等级与经验值；连续学习 / 正确操作 / 止损 / 复盘 / 不追高 / 交易统计
- 10 枚投资勋章（如「连续 7 天没有追高 → 冷静投资者」）

**AI 历史准确率**
- 每条推荐落库并回补现价判定胜负，展示近 30 天推荐数 / 上涨数 / 成功率
- 支持查看历史推荐明细

**AI 投资日记**
- 每日自动生成：今日市场 / 今日操作 / 今日收益 / 今日总结

**AI 解释（可解释性）**
- 任意建议可展开「为什么」：五维评分 + 用户匹配度 + 最终评分 + 行为提示

**Beta 反馈系统**
- 全局右下角 🐞 常驻入口，支持 Bug / 建议 / 星级评分 / 截图 / 联系方式

**Beta 版本标识**
- 首页与「我的」页展示 `Project Phoenix · Beta · Version 0.7`

### 变更

- Today / Discover / Portfolio / Coach / 个股详情 **全部改为调用 AIMS**，消除多套结论
- `ai/advice.ts`、`ai/recommend.ts` 降级为 AIMS 适配层，不再自行决策
- 「我的」页重构：接入成长 / 准确率 / 日记 / 反馈四大面板

### 修复

- 修复 10 处 TypeScript 编译错误（`userMatch` 类型误用、未使用导入、死代码 `matchSector`、`StreakKey` 索引类型等）

## v0.8 — Beta Online：可交付上线

**发布日期**：2026-08-04　｜　**版本目标**：让真实用户能访问并注册登录体验　｜　**Sprint**：S2
**RFC**：`docs/rfc/RFC-001-V0.8-Beta-Online.md`（已批准）

### 新增

**生产行情网关**
- `api/gw/[...slug].ts` — Vercel Serverless Function，替代 vite dev proxy 的 8 条规则
- 覆盖全部上游：东财实时/历史/搜索、新浪快照、腾讯快照/K线、新浪分钟线、同花顺主数据源
- GBK 编码原样透传（新浪数据不乱码），边缘缓存 5s，GET-only 防滥用
- `vercel.json` rewrites 使前端代码零改动（`src/services/http.ts` 相对路径不变）

**健康检查端点**
- `api/health.ts` — GET `/api/health` 存活探针；`?deep=1` 逐个探测 8 个上游可达性与延迟
- **部署后必须第一时间跑 deep 模式**，验证境外机房能否访问国内行情源（风险 R1）

**Supabase 登录认证**
- 邮箱 + 密码登录/注册（非 Magic Link——避免 Supabase 免费邮件频控导致测试用户收不到链接）
- `AuthGate` 门禁组件：未登录不得进入应用主体；未配置 Supabase 时自动放行（本地开发不被阻断）
- 「我的」页设置卡内新增「当前账号 / 退出登录」入口
- 报错自动翻译为中文（密码错误 / 已注册 / 格式不对 / 网络失败等）
