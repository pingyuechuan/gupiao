## 3. 功能测试用例

### 3.1 AIMS 一致性（**最高优先级**）

| ID | 用例 | 预期 |
|---|---|---|
| AIMS-01 | 同一 `secid` 在发现页与详情页 | `composite` / `action` **完全一致** |
| AIMS-02 | 五维权重 | 每维 `weight === 0.2`，合计 1.0 |
| AIMS-03 | 风险维度 | `score = 100 - rawLevel`，UI 反色 |
| AIMS-04 | 上涨概率边界 | 恒在 `[30, 92]` |
| AIMS-05 | 建议仓位 | 恒在 `[0, 100]`，且不超过风险/画像上限 |
| AIMS-06 | 旁路检测 | 页面层不得出现 `computeTradeSignal` / `deriveMetrics` 直调 |

### 3.2 AI 记忆与行为矫正

| ID | 用例 | 预期 |
|---|---|---|
| MEM-01 | 连续 2 次追高后，查询涨幅 >5% 的股票 | `action` = 观望，仓位 ×0.4，有 `behavioralNote` |
| MEM-02 | 记录一次买入（涨幅 6%） | `chasedHigh = true` |
| MEM-03 | 记录一次买入（涨幅 2%） | `chasedHigh = false` |

### 3.3 成长 / 准确率 / 日记

| ID | 用例 | 预期 |
|---|---|---|
| GRW-01 | 每日首次打开 | 经验 +1 次每日奖励，**同日重复打开不重复加** |
| GRW-02 | 等级换算 | `level = floor(xp/120)+1`，上限 100 |
| GRW-03 | 连续天数跨日 | 隔天继续 +1，断天归 1 |
| ACC-01 | 无记录时 | 显示空态，**不显示 0% 或 NaN** |
| DIA-01 | 每日自动生成 | 同日仅一条，不重复生成 |

### 3.4 降级与容错

| ID | 用例 | 预期 |
|---|---|---|
| ERR-01 | 断网打开所有页面 | 全部显示空态/骨架，**0 崩溃** |

| ERR-03 | 全数据源失败 | `EmptyHint` + 重试按钮 |
| ERR-04 | localStorage 被清空 | 回到 Onboarding，不报错 |

## 4. 3 秒法则验收（产品级，人工）

每个页面首屏截图，交给**未参与开发的人**看 3 秒，问："你现在知道该干什么吗？"

| 页面 | 通过标准 |
|---|---|
| 首页 | 能说出"今天大盘能不能做" |
| 发现 | 能说出"哪只值得看、该怎么操作" |
| 持仓 | 能说出"持有还是减仓" |
| 教练 | 能说出"今天的行动计划" |
| 详情 | 能说出"能不能买、买多少、止损在哪" |

**答不上来 = 不通过**，即使功能全部正常。
