## 需求五问（评审模板）

| # | 问题 |
|---|---|
| 1 | 用户真的需要吗？ |
| 2 | 用户每天会打开吗？ |
| 3 | 能提高留存吗？ |
| 4 | 能形成竞争优势吗？ |
| 5 | 以后容易维护吗？ |

**≥3 个「否」→ 拒绝开发，并给出更好的方案。**

## 五、流转规则

```
用户反馈 / 内部想法
        ↓
   待评审（本文档 §3）
        ↓  产品负责人五问评审
   ┌────┴────┐
批准         否决（记录理由 + 替代方案）
   ↓
排入 Roadmap 某个版本
   ↓
进入 Sprint 开发
```

**禁止跳过评审直接开发。禁止在 Sprint 中途插入需求。**
